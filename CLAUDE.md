# Instructions for Claude working in this repo

This repo runs a controlled experiment: does giving a vision-language model the same problem as an image instead of text change its accuracy?

- If you are running on the **lab server**, you are the RUNNER. Follow the loop and rules in `COLLAB.md`, and do the tasks in `TASKS.md` in order.
- `config/experiment.yaml` and `prompts/templates.md` are the fixed design. Do not change them without an `APPROVED` message in COLLAB.md.
- Never write paper text. Never commit secrets or model weights.
